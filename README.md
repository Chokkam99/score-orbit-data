# ScoreOrbit data

Public data file for the ScoreOrbit app: upcoming international badminton events with Indian and Singaporean entries.

- `upcoming.json`: schema version 1. Each event lists its sources and the date they were read.
- Facts come from public sources (tournament calendars, federation announcements, sports news). Nothing here is guessed; unconfirmed entry lists are left empty.
- Updated weekly by a reviewed pull request.
